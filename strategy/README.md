# 黄金期权双买策略 (Gold Options Long Straddle Strategy)

## 策略概述

同时买入相同到期日、相同行权价的看涨和看跌期权，做多波动率，在重大事件前低隐波环境下入场，捕捉波动率飙升和方向性暴击的超额收益。

## 核心逻辑

- **Long Vega**: 隐含波动率上升时，期权时间价值膨胀
- **Long Gamma**: 标的大幅波动时，Delta 加速变化带来非线性收益
- **方向中性**: 不依赖行情方向判断

## 入场条件

1. 隐含波动率处于历史低位（低于 25 分位）
2. 未来 5 个交易日内存在重大事件（如 FOMC、非农、CPI）
3. 期权剩余期限 7-30 天
